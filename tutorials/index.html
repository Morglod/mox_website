    Language basics

    Variables and types
    Declare variables, use the basic types, structs, enums, arrays, slices and strings.
    Operators
    Math, comparison, bit operations, casts, vector math with swizzling and the pipe operator.
    Pointers
    Take an address, read through a pointer, access fields and move pointers by bytes.
    Control flow
    if, while, for, switch and defer.
    Functions
    Declare functions, use default arguments, overloading, function pointers and C functions.
    Modules
    Import other files, name imports, and re-export from a module.
    Generics
    Write functions and structs that work for many types, using compile time parameters.

    Memory

    Zero is initialization
    Design types so that all-zero memory is a valid, ready to use value. No constructors needed.
    Allocators
    Allocate and free memory with allocators, and swap the allocator for code you call.
    Arenas
    Use arenas and temp buffers for fast short-lived memory.
